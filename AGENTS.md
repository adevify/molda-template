# Agent Instructions

Before any action, read and follow:

1. `FIRST.md`
2. `CODER.md`
3. `project/project.md`
4. `project/workflow.md`
5. the Markdown documents for every completed workflow phase
6. `docs/README.md` and the concern documents it requires for the active task

The branch name must equal the project key. During preview phases, enforce the authored
path allowlist in `CODER.md`; reuse installed `@molda-org/*` declarations, extend only
missing project metadata, and do not implement application or backend code.

Treat `docs/code-rules/` as normative after the relevant workflow gate opens. Treat
`docs/examples/` as structural references only. An example never overrides a phase
gate, accepted project requirement, authorization boundary, or module contract.
