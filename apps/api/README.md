# API application

Reserved for the API application selected during architecture. Do not add API code
during project survey, design survey, preview generation, or design iteration.

After the build gate opens, the implementation must follow the Node.js, tRPC, Zod,
MongoDB, Composer, common MCP, events, security, testing, and composition contracts
routed from [`../../docs/README.md`](../../docs/README.md). Do not expose an ordinary
tRPC procedure as an LLM tool merely because its router is registered.
